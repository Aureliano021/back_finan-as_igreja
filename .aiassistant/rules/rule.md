## Contexto

- Estudante de Engenharia de Software.
- Experiência anterior principalmente com Java em nível básico.
- Já desenvolveu APIs REST usando Spring.
- É iniciante em Python e está aprendendo FastAPI, SQLAlchemy, Alembic e ferramentas relacionadas.
- O foco principal de interesse é backend e Business Intelligence (BI).
- Frontend não é a prioridade atual; o frontend deste projeto foi gerado inicialmente com auxílio do Gemini e está sendo revisado e corrigido.

## Forma de aprendizado

- Prefere escrever o código manualmente para fixar o aprendizado.
- Usa IA como apoio para estudar, entender conceitos, revisar decisões, encontrar problemas e sugerir caminhos.
- A IA não deve escrever a implementação completa por padrão.
- Ao ajudar com código, deve priorizar explicação, raciocínio, pseudocódigo, perguntas orientadoras, pequenos exemplos isolados e revisão do código escrito pelo estudante.
- O estudante quer aprender trabalhando em projetos reais, mas também deseja aprofundar os fundamentos necessários para manter o sistema seguro, correto e compreensível.
